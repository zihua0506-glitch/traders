# 入场信号聚合与风控计算工具

基于 **±100 分加权评分体系**，聚合全部技术指标信号，输出综合方向判断、具体入场价格、四种止损方法和动态 R/R 目标。

## CLI 调用方式

```bash
python tools/entry_signal.py <SYMBOL>
```

### 示例

```bash
python tools/entry_signal.py NVDA
python tools/entry_signal.py BTC
python tools/entry_signal.py AAPL
```

## 评分体系 (满分 ±100)

| 维度 | 满分 | 子指标 |
|------|------|--------|
| 趋势结构 | ±35 | SuperTrend(±20) + SAR(±10) + Ichimoku(±5) |
| 资金动量 | ±30 | MACD(±12) + CMF(±10) + VWAP位置(±8) |
| 情绪极值 | ±20 | RSI背离(±12) + RSI极值(±5) + Williams%R(±3) |
| 宏观背景 | ±15 | MA200(±10) + MA50(±5) |
| 市场状态修正 | × | CHOP趋势市 × 1.2 / CHOP震荡市 × 0.7 |

## 信号分级

| 评分 | 方向 | 含义 |
|------|------|------|
| ≥ 65 | 强烈做多 | 多信号共振，高置信度 |
| 40 ~ 64 | 偏多 | 做多信号为主，注意风险 |
| -39 ~ 39 | 中性 | 观望，等待明确信号 |
| -40 ~ -64 | 偏空 | 做空信号为主 |
| ≤ -65 | 强烈做空 | 空头共振，高置信度 |

## 核心输出

### ① 四种止损方法

| 方法 | 逻辑 | 适用场景 |
|------|------|--------|
| ATR止损 | 价格 ± 2×ATR | 趋势强劲，波动率参考 |
| 结构止损 | SuperTrend轨道 + 摆动极值 + 0.3×ATR缓冲 | 结构分析精确止损 |
| VWAP止损 | VWAP ± 0.2×ATR | 机构成本线参考 |
| 百分比止损 | 固定 1% / 2% / 3% | 简单执行，快速计算 |

### ② 三种入场策略

| 策略 | 价格区间 | 适用条件 |
|------|--------|--------|
| 市价入场 | 当前价立即执行 | 评分 ≥65 + 趋势市，信号极强 |
| 回踩入场 | VWAP / SuperTrend 支撑区 | 评分 40~64，等待确认回踩 |
| 突破入场 | 近期摆动高/低点 | 任意评分，要求突破确认 |

### ③ 动态 R/R 目标

| 市场状态 | 保守目标 | 正常目标 | 积极目标 |
|---------|--------|--------|--------|
| 趋势市 (CHOP < 38.2) | 1.5R | 3.0R | 5.0R |
| 过渡状态 | 1.0R | 2.0R | 3.5R |
| 震荡市 (CHOP > 61.8) | 0.8R | 1.5R | 2.5R |

> ATR 高于均值时 R/R ×0.85（风险大，目标保守）；低于均值时 ×1.15（波动小，可以追更远）

## 完整分析流程

```bash
# Step 1: 获取综合入场信号
python tools/entry_signal.py NVDA

# Step 2: 与底层分析工具交叉验证
python tools/trend_structure.py NVDA      # 验证趋势结构评分
python tools/smart_money.py NVDA          # 验证资金动量评分
python tools/votality_risk.py NVDA        # 获取市场状态(CHOP)

# Step 3: 确定仓位大小
python tools/position_sizing.py NVDA <账户资金> <入场价> <止损价>
```

## 输出格式要求

最终报告必须包含：

1. **综合评分**: 分值 + 方向 + 置信度 + 市场状态 (趋势/震荡/过渡)
2. **入场策略**: 三种入场价格区间，推荐最优策略
3. **止损方案**: 四种止损价位，推荐最优止损
4. **止盈目标**: 保守/正常/积极三级 R/R 目标价
5. **信号明细**: 各维度评分贡献，说明哪些信号在支撑判断

## 关键原则

- **评分 < ±40 时不建议入场**: 信号不明确，宁可观望
- **CHOP > 61.8 时降低 R/R 预期**: 震荡市中趋势不持续
- **结构止损优先**: 最符合市场逻辑，但需配合位置管理
- **必须给出具体价格**: 止损/止盈/入场必须是确切的美元/USDT 值
