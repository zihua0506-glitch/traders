# 仓位管理与资金管理工具

提供**三种仓位计算模型**，核心思路：先确定"可以亏多少"，再倒推"能买多少"。每笔交易风险 ≤ 账户 1-2%，才能在连续亏损中存活。

## CLI 调用方式

```bash
python tools/position_sizing.py <SYMBOL> <账户权益> <入场价> <止损价> [--risk <风险比例>] [--winrate <胜率>] [--rr <盈亏比>]
```

### 参数说明

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| SYMBOL | str | 是 | 标的代码，用于获取当前 ATR |
| 账户权益 | float | 是 | 账户总资金 (USD) |
| 入场价 | float | 是 | 计划入场价格 |
| 止损价 | float | 是 | 硬止损价格 |
| --risk | float | 否 | 每笔风险比例，默认 0.01 (即 1%) |
| --winrate | float | 否 | 历史胜率 (0~1)，用于凯利公式，默认 0.5 |
| --rr | float | 否 | 历史平均盈亏比，用于凯利公式，默认 2.0 |

### 示例

```bash
# 基础用法: 账户 10000 美元，NVDA 入场 900，止损 880
python tools/position_sizing.py NVDA 10000 900 880

# 指定风险比例为 2%
python tools/position_sizing.py NVDA 10000 900 880 --risk 0.02

# 使用凯利公式: 历史胜率 55%，平均盈亏比 2.5
python tools/position_sizing.py NVDA 10000 900 880 --winrate 0.55 --rr 2.5
```

## 三种仓位模型

### ① 固定风险模型 (Fixed Risk) — 最常用

```
单位数 = (账户权益 × 风险比例) / |入场价 - 止损价|
```

- 保证每笔亏损严格控制在账户 N% 以内
- 不受胜率影响，适合所有交易者
- 默认风险: 1% (保守) / 2% (标准) / 3% (激进)

### ② 凯利公式 (Kelly Criterion) — 理论最优

```
f* = W - (1-W)/R
半凯利 = f* × 0.5      # 实际使用半凯利，避免过度下注
最大上限 = 25%          # 硬性上限，防止极端情况
```

- W = 历史胜率，R = 平均盈亏比
- 半凯利比全凯利更安全，回撤更小
- 胜率 < 40% 时凯利公式可能给出负值 (建议观望)

### ③ 波动率调整模型 (Volatility Adjusted)

```
调整系数 = clip(目标ATR% / 当前ATR%, 0.3, 2.0)
调整后单位数 = 固定风险单位数 × 调整系数
```

- 高波动时缩小仓位 (系数 < 1)，低波动时放大仓位 (系数 > 1)
- 目标 ATR% 默认 2%，调整范围限制在 30%~200%
- 需要从实时数据获取当前 ATR

## 输出格式要求

最终报告必须包含：

1. **固定风险模型**: 推荐单位数 + 风险金额 + 止损距离% + 所需杠杆
2. **凯利公式**: 凯利比例 + 半凯利 + 推荐权益比例 + 预期对数增长
3. **波动率调整**: 调整后单位数 + 波动率修正系数 + 原因说明
4. **综合建议**: 三模型对比，给出最终推荐仓位 (保守/标准/激进)
5. **风险提示**: 最大连续亏损容忍次数 + 账户爆仓风险评估

## 完整使用流程

```bash
# Step 1: 先获取入场信号和止损位
python tools/entry_signal.py NVDA

# Step 2: 用报告中的入场价和止损价计算仓位
python tools/position_sizing.py NVDA 50000 900.5 885.0 --risk 0.01

# Step 3: 如有历史绩效数据，添加凯利公式参数
python tools/position_sizing.py NVDA 50000 900.5 885.0 --winrate 0.55 --rr 2.5
```

## 关键原则

- **1% 规则**: 新手和波动市场中，单笔风险不超过账户 1%
- **最大 2%**: 有把握的标准交易，上限 2%，超过必须降低仓位
- **凯利仅供参考**: 胜率数据需足够样本 (≥ 30 笔) 才有统计意义
- **波动率高时强制减仓**: ATR 超过均值 50% 以上，建议系数调低至 0.5
- **杠杆 > 3× 需谨慎**: 杠杆过高时，即使方向对也可能被波动洗盘
